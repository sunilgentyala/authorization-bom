ABOM

Authorization Bill of Materials — a portable evidence manifest for human, workload, service, and AI-agent access.

What this is, precisely: a schema and interoperability contribution, not a novel detection algorithm. Effective-permission graphs, delegation-reachability analysis, and separation-of-duty detection all have real prior art (commercial and academic) — disclosed in the novelty gate. What appears to be missing is a shared, versioned artifact recording authorization state itself (declared / approved / computed / observed / revoked) across human, workload, service, and AI-agent identities together.

Why ABOM

The full comparison against standards, academic prior art, and commercial tooling is in research/comparison_matrix.md. Three properties are what this project claims as advancing the state of the art, each stated at the narrowest defensible scope — none of them requires a new detection algorithm.

  • Cross-identity-type coverage in one document. No standard, product, or preprint found in the novelty-gate review carries human, workload, service, and AI-agent identities inside the same versioned, portable schema.
  • Full-lifecycle state, not a snapshot. Declared, approved, computed, observed, exception, revoked, and unverified are distinct, coexisting states, so a consumer sees not just what access exists now but how it was arrived at and whether it was independently observed.
  • An evidence-completeness contract. Every code path that cannot fully resolve a grant's provenance marks it partial or missing rather than silently defaulting to granted or denied — enforced in the engine and covered by dedicated negative tests, not just stated as intent.

Quick start

git clone https://github.com/sunilgentyala/authorization-bom.git
cd authorization-bom
python -m pip install -e ".[dev]"

authbom generate --seed 42 --tenants 2 --output manifest.json
authbom validate manifest.json
authbom analyze manifest.json --now 2026-07-29T12:00:00 --output analysis.json
authbom report analysis.json --format markdown --output report.md
